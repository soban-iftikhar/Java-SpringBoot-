# ☕ Java & Spring Boot: 0 to Master

Welcome to the ultimate, zero-to-master repository for learning **Java and Spring Boot**! 

Whether you are an absolute beginner writing your first `Hello World`, or a seasoned developer looking to crush technical interviews by mastering edge cases, memory management, and advanced language features—this repository is built for you.

Unlike traditional tutorials that gloss over the hard parts, the code and notes in this repository are uniquely structured to take you from **Level 0 (Beginner)** to **Level 1 (Master)** in the exact same file. You'll learn *how* it works, and then immediately learn how to *master* it.

---

## 📂 Repository Structure

The repository is divided into logical, progressive modules. Each directory contains fully documented Java source code as well as a dedicated `theoretical notes.md` file for deep-dive concepts.

### 1. [Basics of Java](./Basics%20of%20Java/)
The foundation of your Java journey.
* **What you'll find:** Variables, Literals, Type Casting, Operators, Conditional Statements, Loops, and Methods.
* **Master Concepts Covered:** Floating-point precision loss (`BigDecimal`), Two's complement bitwise math, Switch Expressions (`yield`), Type promotion rules, Pass-by-Value mechanics, and the famous **Interview Cheat Sheet**.

### 2. [OOP (Object-Oriented Programming)](./OOP/)
The core paradigm of Java. 
* **What you'll find:** Classes, Objects, Constructors, and Arrays of Objects. *(More topics like Inheritance, Polymorphism, and Abstraction coming soon!)*
* **Master Concepts Covered:** Constructor chaining with `this()`, the execution order of Static vs. Instance initialization blocks, Anonymous objects, and **Memory Management** (how Local Variables use the Stack, and Objects use the Garbage-Collected Heap).

### 3. [DSA (Data Structures & Algorithms)](./DSA/)
Writing efficient, memory-safe code.
* **What you'll find:** Single-Dimensional Arrays, Multi-Dimensional Arrays. 
* **Master Concepts Covered:** In-place array reversal (Two-Pointer algorithm), Matrix Transposition, Jagged (Ragged) Arrays for memory optimization, the `Arrays` utility class, and the structural drawbacks of using basic Arrays.

### 4. [Theoretical Notes](./theoretical%20notes.md)
The central hub for theory. If you want to understand the "why" behind the code, start here. It covers the grand architecture of the Java Ecosystem (the exact differences and relationships between the **JDK**, **JRE**, and **JVM**).

---

## 🛠️ How to Use This Repository

1. **Read the Theory:** Start with the `theoretical notes.md` in each directory to grasp the concepts and memory architecture.
2. **Explore the Code:** Open the `.java` files. 
   - Read the **`--- LEVEL 0: BEGINNER ---`** sections to understand the syntax and basic implementation.
   - Scroll down to the **`--- LEVEL 1: MASTER ---`** sections to see advanced edge cases, performance traps, and complex examples.
3. **Run the Code:** Every `.java` file is designed to compile flawlessly. Run them locally to see the output for yourself!
